# Requirements: Hovedvindue og arbejdsflader

- Hovedvinduet skal have tydelig aktiv person, filkontekst og gemmestatus.
- Personlisten skal kunne filtreres uden at editoren mister valgt person.
- Editor og preview skal være den centrale arbejdsflade.
- Fejl, tomme tilstande og ugemte ændringer skal være visuelt entydige.
- Layoutet skal kunne ændres størrelse uden at skjule primære handlinger.

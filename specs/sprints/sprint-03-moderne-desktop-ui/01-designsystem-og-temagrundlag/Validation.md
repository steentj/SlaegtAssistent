# Validation: Designsystem og temagrundlag

## Definition of Done
- [ ] Lyst og mørkt tema kan vælges og genindlæses efter genstart.
- [ ] Systemstandard følger Avalonias systemvariant.
- [ ] Primære kontroller har synlig hover-, focus- og disabled-state.
- [ ] Primære layouts bruger spacing-trin 4, 8, 12, 16 og 24.
- [ ] Tekst og interaktive elementer har dokumenteret kontrast i begge temaer.

## Verifikation
1. Manuel visuel gennemgang af hovedskærmen og centrale kontroller.
2. Kontrol af keyboard-navigation for focus-state.

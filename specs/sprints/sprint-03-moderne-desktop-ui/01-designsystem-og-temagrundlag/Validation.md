# Validation: UI-modernisering med målbare kriterier

## Definition of Done
- [ ] Spacing følger fast skala (mindst 4, 8, 12, 16 px-trin i primære layouts).
- [ ] Interaktive elementer har synlig hover-state.
- [ ] Interaktive elementer har synlig focus-state ved tastaturnavigation.
- [ ] Læsbarhed/kontrast er forbedret i centrale visninger.

## Verifikation
1. Manuel visuel gennemgang af hovedskærmen og centrale kontroller.
2. Kontrol af keyboard-navigation for focus-state.

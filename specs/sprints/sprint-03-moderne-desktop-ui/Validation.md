# Validation: Sprint 03 – moderne desktop-UI og temaer

## Definition of Done

- [ ] Alle fire features har egne plan-, krav- og valideringsfiler.
- [ ] Temaindstilling, visuelle ressourcer og hovedlayout er dækket af tests eller manuel verifikation.
- [ ] Lyst, mørkt og systemstyret tema er kontrolleret.
- [ ] Tastaturnavigation, tom tilstand, aktiv person og ugemte ændringer er kontrolleret.
- [ ] App- og Core-tests er grønne.

## Manuel matrix

Kontrollér hovedvindue, personliste, editor, preview, indstillinger og fejltilstand i alle tre temaer samt ved smal og bred vinduesstørrelse.

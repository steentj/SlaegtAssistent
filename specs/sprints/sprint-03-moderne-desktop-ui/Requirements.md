# Requirements: Sprint 03 – moderne desktop-UI og temaer

- Appen skal tilbyde lyst, mørkt og systemstyret tema.
- Temaet skal gemmes lokalt og anvendes ved næste opstart.
- Eksisterende fil-, GEDCOM-, editor- og previewkommandoer skal bevare deres adfærd.
- Hovedvinduet skal fungere ved både kompakt og bred desktopstørrelse.
- Keyboard navigation, focus-state og læsbar kontrast skal være synlig i begge temaer.
- Alle UI-tekster og dokumentation skal være på dansk.
- Ingen cloudafhængighed må introduceres.

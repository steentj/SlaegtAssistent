# Krav: Sprint 7C

| Id | Acceptkrav | Feature |
| --- | --- | --- |
| B-01 | Eksport følger valgte dokumenters aktuelle body, inklusive ugemte tekster; ingen genrendering, autosave eller dirty-ændring | 01 |
| B-02 | Frontmatter, interne markører og UI-markører medtages ikke; dansk tekst og fri biografi bevares | 01 |
| B-03 | DOCX, PDF og ODT indeholder overskrifter, lister, tabeller, noter, kilder og tilladte lokale billeder | 01 |
| B-04 | Intern personnavigation i samlet dokument bruger bogmærker; andre links følger dokumentkontrakten | 01 |
| B-05 | Eksterne ressourcer og stiudbrud giver advarsler/pladsholdere uden hentning | 01 |
| B-06 | Aktuel/valgte/alle op til 100 biografier kan eksporteres samlet eller separat; navnesammenfald håndteres stabilt | 02 |
| B-07 | Udvalg, mål, overskrivning og advarsler er gennemgåelige; annullering og delvis publicering rapporteres præcist | 02 |
| B-08 | Samlet biografi-PDF kan åbnes til udskrift gennem 7B's flow | 02 |
| B-09 | Printlayout er visuelt kontrolleret; DOCX/ODT kan redigeres i faktiske kontorprogrammer | 03 |
| B-10 | Pakkede apps virker uden system-Python/Pandoc/Graphviz og uden netværk på de tre målplatforme | 03 |
| B-11 | Editor, import, genrendering, personlinks, graf og skabeloneditor består samlet regression | 03 |

Der stilles ikke krav om brugerdefineret boglayout, automatisk grafbilag, HTML-eksport som selvstændigt brugerformat eller pixelidentiske sider i alle kontorprogrammer.

# Validation: Kandidatbaseret genrendering

- [ ] Core- og App-tests er grønne.
- [ ] Skabelonændring giver kandidatdiff uden at ændre fri tekst.
- [ ] Ny GEDCOM-oplysning vises som kandidat med GEDCOM valgt som standard.
- [ ] Afvist kandidat ændrer ikke dokumentet.
- [ ] Godkendt kandidat ændrer kun genereret sektion og markerer editoren som ugemt.
- [ ] Dokument uden markører bevares og tilbydes migrering.
- [ ] Manuel validering er gennemført.

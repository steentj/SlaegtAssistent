# Validation: Editormodel og generering

- [ ] En standardmodel genererer et semantisk gyldigt dokument.
- [ ] Samme model og data giver byte-identisk tekst ved gentagne kørsler.
- [ ] En skabelon i det nye format kan indlæses igen med samme model.
- [ ] Skjulte og flyttede blokke bevares ved genåbning.
- [ ] En ukendt modelversion afvises med dansk forklaring.
- [ ] Core-projektet har ingen ny Avalonia-afhængighed.
- [ ] Målrettede Core-tests består.
- [ ] Den genererede standardskabelon er manuelt gennemgået og godkendt.

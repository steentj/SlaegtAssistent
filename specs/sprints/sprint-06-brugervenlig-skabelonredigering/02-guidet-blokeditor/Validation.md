# Validation: Guidet blokeditor

- [ ] En blok kan tilføjes, skjules, vises og flyttes med mus og tastatur.
- [ ] Faktafelter kan vælges og ordnes uden tekniske feltnavne.
- [ ] Understøttede liste-/tabelvalg kan ændres; ugyldige valg kan ikke foretages.
- [ ] Fortryd og gendan virker for alle modelændringer i sessionen.
- [ ] Nulstilling kræver bekræftelse og kan annulleres.
- [ ] Ingen standardskærm viser `{{`, `#each` eller engelske feltstier.
- [ ] Gem, annuller og fejl er synlige ved minimumsstørrelse og 200 % skalering.
- [ ] ViewModel-tests og relevante headless UI-tests består.
- [ ] Manuel tastaturgennemgang er godkendt.

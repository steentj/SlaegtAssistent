# Requirements: Tilgængelighed, hjælp og regression

- Alle kontroller og blokke skal have meningsfulde danske tilgængelighedsnavne.
- Hele hovedforløbet skal kunne gennemføres med tastatur og synlig fokusmarkering.
- Status og fejl må ikke formidles med farve alene.
- Handlingsknapper skal forblive synlige ved minimumsstørrelse og 200 % skalering.
- Hver bloktype skal have kort kontekstuel hjælp og et eksempel på resultatet.
- Hjælpen skal beskrive den guidede editor uden at undervise i det tidligere skabelonsprog.
- Mindst tre uerfarne it-brugere skal inviteres til den definerede hovedopgave.
- Mindst 80 % skal gennemføre på højst fem minutter uden hjælp.
- Tests for det udfasede skabelonformat kan erstattes. Bevarede import-, preview-, personlink- og synkroniseringsforløb skal fortsat være grønne med den nye model.

# Validation: Eksempeldata og live preview

- [ ] Et fyldestgørende preview vises uden indlæst GEDCOM.
- [ ] En faktisk indlæst person kan vælges og fravælges igen.
- [ ] Flytning, skjul og liste-/tabelvalg ses automatisk i preview.
- [ ] Hurtige ændringer viser kun det seneste renderingsresultat.
- [ ] En renderingsfejl bevarer sidste gyldige preview og viser en dansk fejl.
- [ ] Samme model og person giver samme Markdown i editor- og produktionsflow.
- [ ] Eksterne links, billeder og rå HTML medfører ingen netværkskald eller scriptkørsel.
- [ ] Målrettede Core-, App- og sikkerhedstests består.
- [ ] Manuel preview-sammenligning er godkendt.

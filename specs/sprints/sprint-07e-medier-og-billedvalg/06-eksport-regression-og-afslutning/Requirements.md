# Krav: Eksport, platforme og samlet accept

Status: **planlagt**. Fælles kontrakt: [Mediekontrakt.md](../Mediekontrakt.md).

| Id | Acceptkriterium |
| --- | --- |
| E01 | Topbillede og livsforløbsbilleder er med i preview, PDF, DOCX, ODT og udskrifts-PDF. |
| E02 | Eksport fra ugemt buffer og batch følger samme lokale rod- og fejlpolitik. |
| E03 | Alle aftalte regressions-, ydelses-, native platform- og AOT-prøver er dokumenteret. |
| E04 | Hjælp beskriver liste/tabel, manuelt billedvalg, relative stier og historikkens afgrænsning. |

Alle brugerrettede tekster er danske. Funktionaliteten arbejder lokalt og respekterer eksisterende atomisk gemning, editorcache og arbejdsområdespærring. Core og ViewModels må ikke få Avalonia-typer.

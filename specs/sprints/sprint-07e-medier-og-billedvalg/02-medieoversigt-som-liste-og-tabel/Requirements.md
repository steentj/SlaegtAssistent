# Krav: Medieoversigt uden automatiske billeder

Status: **planlagt**. Fælles kontrakt: [Mediekontrakt.md](../Mediekontrakt.md).

| Id | Acceptkriterium |
| --- | --- |
| O01 | Nye standarddokumenter indeholder en medieliste uden automatisk billedsyntaks. |
| O02 | Skabeloneditoren tilbyder liste og tabel med eksisterende metadatafelter. |
| O03 | Tidligere Standard-medieblok kan åbnes og renderes som liste uden datatab. |
| O04 | Eksisterende dokumenter ændres kun via godkendt kandidat, og fri tekst bevares. |

Alle brugerrettede tekster er danske. Funktionaliteten arbejder lokalt og respekterer eksisterende atomisk gemning, editorcache og arbejdsområdespærring. Core og ViewModels må ikke få Avalonia-typer.

# Krav: Proportional billedstørrelse

- Brugeren kan ved billedvalg vælge hel, halv eller en kvart sidebredde for topbilleder og billeder i livsforløbet.
- Billeder skaleres proportionalt og overstiger ikke den valgte del af dokumentets tilgængelige sidebredde; små billeder forstørres ikke automatisk.
- Størrelsen gemmes sammen med billedets Markdown og bevares ved genåbning, kandidatopdatering og eksport. Ældre billeder uden størrelsesangivelse fungerer fortsat.
- Forhåndsvisning, PDF, DOCX og ODT viser samme relative størrelse. Originalfilen ændres ikke.
- Løsningen arbejder lokalt, accepterer kun de tre fastlagte størrelser og indfører ikke rå HTML eller netværksadgang.

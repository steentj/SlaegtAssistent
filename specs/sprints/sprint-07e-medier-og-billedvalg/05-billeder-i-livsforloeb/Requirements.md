# Krav: Billeder ved markøren i livsforløbet

Status: **planlagt**. Fælles kontrakt: [Mediekontrakt.md](../Mediekontrakt.md).

| Id | Acceptkriterium |
| --- | --- |
| L01 | Et valgt billede indsættes som selvstændig paragraf ved markøren i fri tekst. |
| L02 | Flere billeder kan indsættes i vilkårlig rækkefølge med egen alternativ tekst og billedtekst. |
| L03 | Beskyttede områder og forældede markeringer afvises uden tekstændring. |
| L04 | Gem, Fortryd/Gentag, genstart, eksport og kandidatopdatering bevarer brugerens billeder og tekst. |

Alle brugerrettede tekster er danske. Funktionaliteten arbejder lokalt og respekterer eksisterende atomisk gemning, editorcache og arbejdsområdespærring. Core og ViewModels må ikke få Avalonia-typer.

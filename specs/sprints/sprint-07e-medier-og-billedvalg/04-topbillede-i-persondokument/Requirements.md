# Krav: Ét topbillede pr. persondokument

Status: **planlagt**. Fælles kontrakt: [Mediekontrakt.md](../Mediekontrakt.md).

| Id | Acceptkriterium |
| --- | --- |
| T01 | Hver person kan få højst ét topbillede via kontrollen, helt øverst før den genererede sektion. |
| T02 | Skift/Fjern berører alene den entydige topbilledblok og sletter aldrig originalfilen. |
| T03 | Valget gemmes som Markdown, genåbnes korrekt og bevares ved kandidatopdatering. |
| T04 | Annullering, forkert kontekst og ugyldige markører medfører ingen dokumentændring. |

Alle brugerrettede tekster er danske. Funktionaliteten arbejder lokalt og respekterer eksisterende atomisk gemning, editorcache og arbejdsområdespærring. Core og ViewModels må ikke få Avalonia-typer.

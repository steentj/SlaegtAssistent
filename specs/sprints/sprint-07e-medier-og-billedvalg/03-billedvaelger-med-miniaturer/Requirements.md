# Krav: Fælles billedvælger med miniaturevisninger

Status: **planlagt**. Fælles kontrakt: [Mediekontrakt.md](../Mediekontrakt.md).

| Id | Acceptkriterium |
| --- | --- |
| B01 | Vælgeren viser personens medier som miniaturekort og kan søge i alle godkendte referencer. |
| B02 | Kun læsbare PNG/JPEG inden for budget og rødder kan bekræftes. |
| B03 | Annullering giver ingen dokumentændring; billeder og fejl kan betjenes med tastatur. |
| B04 | Ressourcebudgetter, afbrydelse og cache følger Mediekontrakt.md. |

Alle brugerrettede tekster er danske. Funktionaliteten arbejder lokalt og respekterer eksisterende atomisk gemning, editorcache og arbejdsområdespærring. Core og ViewModels må ikke få Avalonia-typer.

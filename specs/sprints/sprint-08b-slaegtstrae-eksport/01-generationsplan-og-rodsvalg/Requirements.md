# Krav til eksportgrundlag

- **E1.** Enhver kendt aneposition i hovedtræet kan vælges ved nummer, uanset skærmtræets udfoldning eller nummerets dybde. Ukendt position og ugyldigt nummer forhindrer eksport og vises med en dansk forklaring. Eksporten bruger en midlertidig rod med nummer 1. Hovedproband og arbejdsområdets indstillinger berøres ikke. Nummer og navn vises på samme linje med »#« foran nummeret.
- **E2.** Dokumentet indeholder maksimalt seks generationer inklusive roden. Roden står øverst og ældste generation nederst. Ved begge retninger vises efterkommere mellem roden og forfædrene. Forældre og børn placeres inden for tilhørende kolonner. Manglende grene bevarer deres plads, og personer, som optræder i flere grene, vises ved hver position. Tomme generationer udelades.
- **E3.** Ved højst fem personceller vises anenummer, navn, fødselsdato, fødested, dødsdato og dødssted. Ved flere personceller vises anenummer, navn og fødselsår – dødsår. Teksten drejes en kvart omgang ved mere end otte kolonnepositioner, herunder reserverede tomme positioner. Antal personceller afgør, om felterne er detaljerede eller kompakte. Felter bruger A1–A5.
- **E4.** Dokumentet medtager den valgte generations planlagte relationer på tværs af alle grene. Skærmens foldetilstand afgør kun, hvad der er synligt på skærmen.

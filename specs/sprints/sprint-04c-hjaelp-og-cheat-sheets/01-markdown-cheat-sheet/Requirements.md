# Requirements: Markdown-cheat sheet

- Cheat sheetet skal forklare den Markdown-syntaks, som appens preview understøtter.
- Det skal indeholde eksempler på overskrifter, afsnit, lister, tabeller, links, billeder og fremhævet tekst.
- Brugeren skal kunne søge i cheat sheetets indhold.
- Indholdet skal være lokalt og på dansk.
- Vinduet skal kunne åbnes uden at blokere hovedvinduet.

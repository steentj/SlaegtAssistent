# Requirements: Personkontekst og Markdown-rendering

- Rendererens input skal være en stabil, normaliseret kontekst.
- Begivenheder skal kunne vises samlet eller opdelt efter klassifikation.
- Census skal kunne vises som egne poster eller i en samlet begivenhedsgruppe.
- Kilder skal kunne vises inline og i samlet liste.
- Medier skal gengives som relative Markdown-links.
- `SUBM` skal være tilgængelig for skabelonen.
- Samme input og skabelon skal give samme output.
- Manglende data skal udelades eller markeres efter skabelonens betingelser.

# Validation: Personkontekst og Markdown-rendering

- [ ] Core-tests er grønne og output er deterministisk.
- [ ] Et persondokument kan vise fødsel, dåb, vielse, konfirmation, død, census og lægdsrulle.
- [ ] Samme kilde kan bruges flere steder uden dubleret samlet post.
- [ ] Et billede giver et relativt Markdown-link.
- [ ] En manglende mediefil giver en synlig advarsel.
- [ ] `SUBM` kan vises i footer via standardskabelonen.
- [ ] Manuel afprøvning er gennemført, før feature 04 starter.

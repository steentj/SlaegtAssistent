# Plan: Genererede sektioner og diff

1. Skriv failing Core-tests for genererede sektioner og eksisterende fri tekst.
2. Tilføj markører og versionsdata til persondokumentet.
3. Implementér kandidatgenerering ved GEDCOM- eller skabelonændring.
4. Begræns diff og opdatering til den genererede sektion.
5. Håndtér dokumenter uden markører som en ikke-destruktiv migrering.
6. Stop for manuel afprøvning af godkendelse, afvisning og migrering.

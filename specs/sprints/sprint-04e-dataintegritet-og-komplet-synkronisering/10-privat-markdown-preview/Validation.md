# Validation: Privat og kontrolleret Markdown-preview

- [ ] Eksterne billeder og øvrige eksterne ressourcer laver ingen netværksanmodninger.
- [ ] Script, iframe og aktive URL-skemaer udføres ikke.
- [ ] Rå HTML følger den dokumenterede tilladelsesliste eller er deaktiveret.
- [ ] Tilladte lokale billeder vises korrekt.
- [ ] Lokale stiudbrud og ikke-tilladte filer blokeres.
- [ ] Eksterne links kræver eksplicit brugerhandling og viser destinationen.
- [ ] Blokering ændrer ikke Markdown-dokumentet.
- [ ] Hovedpreview og hjælpevinduer bruger samme policy.
- [ ] Alle tre temaer er manuelt kontrolleret.
- [ ] `dotnet build` og `dotnet test` er grønne.
- [ ] Manuel netværksmonitorering viser nul uventede anmodninger.

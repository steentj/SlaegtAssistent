# Referencestile til biografieksport

Filerne er dannet fra Pandoc 3.13's standardreferencer med `python3 scripts/dan-biografireferencer.py`. Scriptet sætter A4, 20 mm margen, dansk som standardsprog og 11 pt grundskrift; overskrifter holdes sammen med efterfølgende tekst. Pandoc og de anvendte standardreferencer skal være tilgængelige lokalt for at genskabe filerne. Scriptet fastlåser zip-filernes tidsstempler, så samme Pandoc-version og Python-miljø giver identiske filer.

Prøvepakkescripterne medtager disse filer. Dette leverer ikke Pandoc selv og dokumenterer ikke visuel kompatibilitet eller rettighederne til en senere Pandoc-distribution; det skal kontrolleres ved pakning.
